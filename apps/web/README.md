# TrustFit web (Next.js)

Display only: every score comes from the API (`NEXT_PUBLIC_API_URL`), which runs `trustfit_engine`.

```bash
npm ci
npm run dev    # http://localhost:3000
npm run lint
npm run build
```

Design tokens (pitch deck) live in `app/globals.css`: `navy`, `blue`, `coral`, `paper`, `ink-muted`,
`verdict-green`, `verdict-amber`, `verdict-red`; fonts are IBM Plex Sans and Mono.
